# Melhorias

## Sistema de autonomia configurável

Criar uma configuração de autonomia que permita ao usuário escolher quando a Friday deve agir diretamente e quando deve pedir confirmação, reduzindo perguntas desnecessárias sem retirar o controle do usuário.

O usuário poderá dizer algo como: “Você pode ter acesso total a partir de agora”. A Friday deve confirmar explicitamente essa mudança com o usuário e, somente após a confirmação, ativar o nível de acesso/autonomia autorizado. O sistema deve deixar claro o escopo e respeitar limites de segurança para ações sensíveis ou críticas.
